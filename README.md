# Customer Accounts Microservice

[![CI Build](https://github.com/maneaditya478-commits/LALIT-3.0/actions/workflows/ci-build.yaml/badge.svg)](https://github.com/maneaditya478-commits/LALIT-3.0/actions/workflows/ci-build.yaml)

A RESTful microservice for managing Customer Accounts, built using Python Flask, SQLAlchemy, Talisman for security headers, CORS support, Docker containerization, Kubernetes deployments, and automated CI/CD pipelines with GitHub Actions and Tekton.
